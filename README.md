# Alcemy Sim

中世ファンタジーの錬金術工房経営ゲーム。冒険者による素材収集、工房設備による自動合成、研究ツリーによる恒常的な成長を組み合わせます。

最小限のゲームとして遊べるMVPです。冒険者の雇用・派遣、設備の配置・自動合成、販売、研究9件、ブラウザーへのセーブと復元を実装しています。

## 遊び方

1. 冒険者ギルドで **イリスを雇う → 派遣**。15秒で素材を持ち帰ります。
2. 調合釜で **自動合成を開始**。薬草と清水から8秒ごとに傷薬を作り、知識を得ます。
3. 在庫の **傷薬を販売**。3個以上作ると、最初の研究に必要な知識が集まります。
4. **森の恵み** などを研究。自動再派遣・蒸留器・遺跡・魔力薬へ進みましょう。

初回の目標は画面上部の5段階の案内で確認できます。設備は購入ボタンを押してから空きマスを選んで配置でき、移動は無料です。画面表示中だけ進行し、5秒ごとと操作時に保存します。セーブは利用中のブラウザーに保存され、別端末には同期しません。

## Codex Cloudでの開発

作業ディレクトリは `/workspace/Alcemy-Sim1`。Node.js 24.19.0 / npm 11.9.0 とCloudにあるChromiumを利用します。外部APIキー、DB、Dockerは不要です。

```sh
cd /workspace/Alcemy-Sim1
bash scripts/setup.sh
npm run dev
```

開発サーバーは5173番ポートを使用します。検証は別のシェルで実行できます。

```sh
npm run check
```

Vitest単体テスト33件、型検査、本番ビルド、通常パスとGitHub PagesパスそれぞれでデスクトップとモバイルのChromium E2E（各12件、計24件）を実行します。E2Eは4173番ポートに専用サーバーを起動して終了時に停止します。結果は `test-results/`、失敗時のtraceや画像も同ディレクトリに出力され、Git管理には含まれません。`CHROMIUM_PATH` で既存のブラウザー実行ファイルを指定できます。
