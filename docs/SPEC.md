# ゲーム仕様 v0.1（MVP）

状態: M1・レビュー対応・UI-1・UI-2を実装済み。基本の数値と保存仕様を維持し、画面構成・専用アート・一巡の反応を更新しました。

## 体験とMVPの完了目標

プレイヤーは中世ファンタジーの小さな錬金術工房の経営者。冒険者に素材調達を任せ、設備と研究に投資して、工房が自律的に回る範囲を広げます。

最初のプレイ目標は「冒険者を雇って派遣し、帰還素材で設備が自動合成した品を販売し、その利益と知識で研究を1件完了する」。最短のシミュレーション進行は約25秒で、操作を含めて約1〜2分の初回体験を想定します。5段階の案内で進捗を表示し、達成後も継続して遊べます。

## 基本ループ

1. 冒険者を雇い、探索先に派遣する。
2. 時間経過で帰還し、共有在庫へ素材が入る。
3. 工房の設備にレシピを割り当てる。材料があれば自動的に1バッチ開始する。
4. 完成品を販売して金貨を得る。合成では知識も得る。
5. 金貨と知識を使い、設備・効率・レシピ・探索先を解放する。
6. 補給と生産の不足を見ながら、派遣先と設備構成を変える。

## 初期データ

- 初期所持: 金貨100、知識0、薬草4、清水2。調合釜を1台配置済み（傷薬を選択、停止状態）。冒険者はイリス20金貨、ローワン40金貨で雇用。どちらも同じ探索先を選べる。初期資金で最初の一巡が成立する。
- 森: 15秒で薬草4・清水2。遺跡: 30秒で魔晶片2・清水2、研究で解放。派遣の都度の費用なし。最初は手動で再派遣し、研究で自動再派遣を解放。
- 傷薬: 薬草2 + 清水1 → 傷薬1、調合釜8秒、販売12金貨、完成時に知識1。
- 薬草エキス: 薬草3 → エキス1、蒸留器12秒、販売16金貨、知識1。蒸留器の研究で解放。
- 魔力薬: エキス1 + 魔晶片1 + 清水1 → 魔力薬1、調合釜20秒、販売40金貨、知識2。レシピ研究で解放。
- 追加の調合釜25金貨、蒸留器45金貨。購入前に配置候補を選び、不正配置では費用を消費しない。移動無料。MVPでは設備の売却・撤去は設けない。停止済みで進行中バッチのない設備は、交換先の購入価格を払って同じマスで交換できる。元の設備の返金はなく、最後の調合釜は交換できない。

## 時間と状態のルール

- シミュレーションは100ms固定tickを基準にする。UIの再描画頻度と独立させ、テストでは明示的に時間を進める。
- 各tickは「派遣帰還 → 合成完了 → 待機設備の合成開始」の順に、安定したID順で処理。自動再派遣は帰還報酬反映後に行う。
- 素材と通貨は非負の整数。バッチ開始時に材料を消費。停止指示は次バッチを止め、進行中バッチは完成させる。移動で進捗を消さない。
- 設備は素材不足時に待機し、不足品を表示。複数設備で同じ材料を二重に使わない。
- 研究による時間短縮は次バッチ、探索報酬増加は次の派遣から適用。進行中の仕事は開始時条件を保持する。
- MVPは画面がアクティブな間だけ進行。非表示・再読込・再開時は経過時間を持ち越さず、閉じている間の進行を計算しない。画面にもこの制限を表示する。
- 表示中にメインスレッドが長時間停止した場合の追いつき計算は1回あたり60秒まで。通常の進行は100ms刻みで、非表示から戻る際はこの追いつき計算も行わない。
- 5秒ごと、および雇用・配置・研究などの操作後に保存。ストレージ書き込み失敗を通知し、黙って保存成功としない。保存には進行中バッチと派遣の残り時間も含める。
- ページ非表示・離脱時にも保存を試みる。セーブキーは互換性維持のため `alcemy-sim-save-v1` のまま、現在の保存形式はschemaVersion 2。破損・未知のversionは自動上書きを止め、確認付きの新規開始を提供する。
- Web Locksで1つのタブだけに更新・保存・初期化を許可する。他タブは待機し、所有タブの離脱後に最新データを読み直す。未対応ブラウザーでは無保護の保存を行わない。
- 旧v1は読み込み時に移行し、最初の書き込み前に旧JSONを `alcemy-sim-save-v1-legacy-backup` に一度だけ保存する。バックアップ失敗時は元データを置き換えない。
- データ形式のschemaVersionと数値ルールのcontentVersionを区別する。進行中ジョブと派遣は開始時のcontentVersionを持ち、保存検証には公開済みの履歴を使う。

## 操作と見た目

夜の青緑と真鍮を基調とする2D管理画面。常設HUDに金貨・知識・保存状態・設定、短い目標バーに次の行動を表示します。工房／冒険者／在庫・販売／研究は切替式。PCは工房と選択設備の主要操作を左右に表示し、モバイルは下部ナビと設備詳細シートへ再配置します。画面内の切替でも合成・派遣は継続し、選択や探索先・各画面のスクロール位置を保持します。

本文は16px、重要な補足は14px、主要タッチ対象は44×44px以上を基準とします。狭い画面では工房内だけを横スクロール可能にし、ページ全体を縮小しません。工房のマスは1つのTab入口から矢印／Home／Endで移動、Enterで選択・配置、Escapeで取消。詳細シートはフォーカスを内部に保ち、閉じた後は元の操作へ戻します。

初回案内は雇用・派遣可能・帰還待ちを区別し、「開く」で対象画面と操作へ案内します。素材不足から冒険者画面へ移動できます。販売は従来どおり全量販売で、個数と売上を事前表示します。移動・交換は設備詳細の「移動・管理」、手動保存・初期化とヘルプは設定へまとめます。UI-2では夜の工房、調合釜、イリス、薬草・清水・傷薬の画像を分離して表示します。釜の炉光・泡は合成中だけ表示し、停止予約したバッチが終わると消えます。配置は従来の6×4のDOM座標を維持します。

合成・帰還・販売・研究の結果は、実処理から得た一時イベントにより短く表示します。同時完成は数量と知識をまとめ、通知は最大2件。イベントは保存せず、再読込・非表示・初期化・タブ引継ぎで過去の演出を再生しません。OSの演出軽減と設定の「動きを控えめにする」に対応し、動きがなくても結果を確認できます。この画面設定はセッション内で保持し、再読込時はOS設定へ戻します。画像を読めなくても名称・状態・操作を保持します。音声とUI-3の残りアートは未追加です。

配置は「設備を選ぶ→マスを選ぶ」を基本とし、ドラッグ操作を必須にしません。研究・設備・派遣の操作には効果、費用、実行できない理由を表示します。色だけで稼働状態を伝えません。
