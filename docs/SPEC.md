## 体験とMVPの完了目標

プレイヤーは中世ファンタジーの小さな錬金術工房の経営者。冒険者に素材調達を任せ、設備と研究に投資して、工房が自律的に回る範囲を広げます。

最初の目標は「雇用・派遣・合成を準備し、1日営業して完成した傷薬を翌日に陳列、客への販売と知識で研究を1件完了する」。準備時間は無制限で、日送りだけが作業・帰還・購買を進めます。初研究は概ね2営業後から可能ですが、客が購入する結果を保証しません。5段階の案内と保存済み日報で進捗を確認します。

## 基本ループ

1. 準備中に雇用・派遣、設備・レシピ・稼働設定を決める。日付や残作業は時間経過で変化しない。
2. 倉庫から品目と数量を棚へ移し、必要な製作用確保数を設定する。
3. 「1日営業する」で各設備・冒険者を並列に150作業進め、来店客の希望と購入を処理する。
4. 完成品・帰還素材は倉庫へ入り、棚の分だけが売れる。当日補充はせず、完成品を翌日陳列する。
5. 状態・売上・棚・成長・日報を一括保存して日報を表示。閉じる操作は精算を繰り返さない。
6. 売上と知識で研究し、補給・製造・需要・棚容量を見ながら次の日を準備する。

## 初期データ

- 初期所持: 金貨100、知識0、薬草4、清水2。調合釜を1台配置済み（傷薬を選択、停止状態）。冒険者はイリス20金貨、ローワン40金貨で雇用。どちらも同じ探索先を選べる。初期資金で最初の一巡が成立する。
- 森: 150作業（1日）で薬草4・清水2。遺跡: 300作業（2日）で魔晶片2・清水2、研究で解放。派遣の都度の費用なし。最初は手動で再派遣し、研究で自動再派遣を解放。
- 傷薬: 薬草2 + 清水1 → 傷薬1、調合釜80作業、販売12金貨、完成時に知識1。
- 薬草エキス: 薬草3 → エキス1、蒸留器120作業（解放時は10%短縮済みで108）、販売16金貨、知識1。蒸留器の研究で解放。
- 魔力薬: エキス1 + 魔晶片1 + 清水1 → 魔力薬1、調合釜200作業（解放時は180）、販売40金貨、知識2。レシピ研究で解放。
- 追加の調合釜25金貨、蒸留器45金貨。購入前に配置候補を選び、不正配置では費用を消費しない。移動無料。MVPでは設備の売却・撤去は設けない。停止済みで進行中バッチのない設備は、交換先の購入価格を払って同じマスで交換できる。元の設備の返金はなく、最後の調合釜は交換できない。

## 日送り・店舗・保存のルール

- 日初0地点で着手し、150作業を進める。日内は帰還→完成→残予算があれば次の着手→客の購買の安定順。日末は新規着手しない。余った未使用予算は貯めず、仕事の正確な残量は持ち越す。
- 材料・金貨・統計は安全な非負整数。製造は倉庫だけを使い、棚は客の購入だけで減る。エキスの製作用確保は初期2、傷薬/魔力薬は0。棚への移動は倉庫の確保数を下回らない。売れ残りは棚へ保持し、入出庫で資産や売上を増やさない。
- 店Lv1/2/3は新店舗の顧客への累計販売0/10/40個で導出。棚枠1/2/3、1枠容量4/6/8、基礎来客4/6/8。知名度は購入客数により最大3/日増え、0〜100。翌日の集客・容量へ反映する。
- 来客数は基礎来客＋floor(知名度/25)＋需要補正（高需要あり+1、全て低需要−1、他0）を3〜12へ制限。需要は低/通常/高を20/60/20%で決め、希望品の基礎重み6/3/1へ倍率1/2/3を掛ける。一客1個、購入意欲80%。希望品なし・欠品・見送りは非購入。係数はこのゲームの初期値で、原作の内部式ではない。
- 店舗販売数Sは購入成立ごとに一度だけ+1。閉店時に再加算せずLvを導出する。価格は12/16/40、名声研究後14/19/48。準備中の手動換金、日末全量換金、当日補充は設けない。
- seed・日・客番号・用途で需要と購買を再現し、再読込・再試行・演出で再抽選しない。結果確認は日報の閲覧だけで、営業の再実行にならない。
- 準備操作も営業も候補を計算してから保存する。失敗時は前の金貨・倉庫・棚・仕事・日数・成長を保ち、成功するまで確定扱いにしない。
- schemaVersion 3を唯一の正本とし、内部worldは既存v2の厳密な世界データ形式を再利用。contentVersion 2を追加し、公開済みversion 1の数値と固定v1/v2 fixtureは維持する。
- v1/v2の全資産・旧仕事・過去統計は保持し、棚なし・新店舗販売/知名度0・移行後第1日から開始。旧tickから暦を捏造せず、移行だけでは報酬を付与しない。
- 最初の移行書き込み前に元JSONを `alcemy-sim-save-v1-before-day-turn-v3` へ一度だけ退避。v1用の `alcemy-sim-save-v1-legacy-backup` も維持し、バックアップ失敗では元記録を置き換えない。
- Web Locksの所有タブだけが変更・保存・初期化する。引き継ぎで最新日・revision・未確認日報を読み直す。未対応環境で無保護の保存をしない。
- 停止予約・配置の合法性・研究前提を維持。進行中仕事の所要量/報酬は開始時条件のまま。実時計は通知・音・保存表示だけに使い、放置/非表示/閉じている時間の進行はない。

## 操作と見た目

夜の青緑と真鍮を基調とする2D管理画面。常設HUDに金貨・知識・保存状態・設定、短い目標バーに次の行動を表示します。工房／冒険者／店・在庫／研究は切替式。PCは工房と選択設備の主要操作を左右に表示し、モバイルは下部ナビと設備詳細シートへ再配置します。画面内の切替では作業を進めず、選択や探索先・各画面のスクロール位置を保持します。

本文は16px、重要な補足は14px、主要タッチ対象は44×44px以上を基準とします。狭い画面では工房内だけを横スクロール可能にし、ページ全体を縮小しません。工房のマスは1つのTab入口から矢印／Home／Endで移動、Enterで選択・配置、Escapeで取消。詳細シートはフォーカスを内部に保ち、閉じた後は元の操作へ戻します。

初回案内は雇用・派遣可能・帰還待ちを区別し、「開く」で対象画面と操作へ案内します。素材不足は不足数と入手先を示し、森・遺跡への派遣、前提研究、蒸留器の配置・操作へ移動できます。移動だけでは雇用・派遣・購入・合成を実行しません。店・在庫で倉庫と棚の数量・確保数・需要・来客予報を表示し、陳列と倉庫戻しを明示操作にします。棚にあるエキスを製造に使うための戻し導線も備えます。移動・交換は設備詳細の「移動・管理」、手動保存・初期化とヘルプは設定へまとめます。夜の工房、調合釜・蒸留器、イリス・ローワン、全6アイテム、森・遺跡の画像を分離して表示します。設備の炉光・泡は合成中だけ表示し、停止予約したバッチが終わると消えます。研究は前提研究へフォーカスでき、解放内容と資源不足、エンジンの関数から求めた効果例を表示します。満杯時は購入を無効にし、停止設備の交換を案内します。配置は従来の6×4のDOM座標を維持します。

合成・帰還・販売・研究の結果は、実処理から得た一時イベントにより短く表示します。同時完成は数量と知識をまとめ、通知は最大2件。一時通知は保存せず、営業の日報・顧客結果は別途保存します。新しい営業の通知は前日分と合算せず、再読込・非表示・初期化・タブ引継ぎで過去の演出を再生しません。演出軽減は初回にOSの設定へ従い、手動の軽減・通常表示やOS追従への復帰も選べます。文字サイズ（100／112.5／125%）、出来事の通知、任意の音と音量を設定できます。音は初期オフ、有効化後の入力操作から短い通知音を使用し、同時完成で多重再生しません。ゲームの記録とは別の `alcemy-sim-ui-preferences-v1` に検証して保存し、不正な設定は初期値へ戻します。設定保存に失敗しても現在画面へ適用し、その失敗を表示します。工房初期化で表示設定は消しません。画像を読めなくても名称・状態・操作を保持します。

配置は「設備を選ぶ→マスを選ぶ」を基本とし、ドラッグ操作を必須にしません。研究・設備・派遣の操作には効果、費用、実行できない理由を表示します。色だけで稼働状態を伝えません。
